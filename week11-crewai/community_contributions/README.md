# Week 11: CrewAI — Community Contributions

Cohort projects for this week live here. One folder per person, named after
your GitHub handle:

```
week11-crewai/community_contributions/<your-github-handle>/
```

Include a short `README.md` in your folder saying what you built and how to
run it. No API keys, no `.env` files.

See [CONTRIBUTING.md](../../CONTRIBUTING.md) for the full flow.
